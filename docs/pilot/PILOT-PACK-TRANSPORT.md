# PILOT-PACK-PREP — Compraventa y transporte

Estado: **PREPARACIÓN**. Este paquete no inicia una prueba real.

## Objetivo del piloto
Validar que una empresa puede crear, seguir y cerrar operaciones de compraventa/transporte con menos coordinación manual, mejor trazabilidad y un flujo móvil comprensible.

## Guion de demostración
1. Crear una compraventa con transporte.
2. Registrar origen, destino, mercancía y condiciones demo.
3. Marcar recogida y tránsito.
4. Añadir una evidencia de entrega simulada.
5. Abrir una incidencia y mostrar revisión humana.
6. Mostrar un porte especial supervisado.
7. Mostrar preparación de transporte animal sin habilitar uso real.
8. Revisar dashboard y recomendación Premium shadow/read-only.

## Métricas a capturar
- tiempo para crear operación;
- tasa de finalización sin ayuda;
- pasos que generan dudas;
- incidencias por operación;
- tiempo de resolución;
- utilidad percibida de timeline/evidencias;
- facilidad de uso móvil;
- valor percibido por empresa, conductor/operador y cliente;
- hipótesis de ahorro de tiempo, siempre medida y nunca garantizada.

## Protocolo de incidencias
Clasificar P0–P3. Cualquier pérdida/corrupción de expediente, problema de seguridad o efecto no esperado detiene el ejercicio afectado y pasa a revisión. Las incidencias jurídicas, bienestar animal o permisos se escalan a revisión profesional cuando proceda.

## Material para inversor o entidad colaboradora
Problema, flujo demostrable, arquitectura de seguridad, límites actuales, métricas objetivo, resultados del piloto cuando existan y roadmap. Diferenciar siempre entre capacidad demostrada, hipótesis y funcionalidad futura.

## Condiciones para prueba real
La prueba real deberá organizarse separadamente por el responsable del proyecto junto con el primer inversor o entidad colaboradora. Requiere autorización específica y gates aplicables; este documento solo prepara el ejercicio.
