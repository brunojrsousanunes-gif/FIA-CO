# PLR-6/8 — Premium y validación comercial

## Agente Premium
Durante esta fase permanece `shadow/read-only`: recomendaciones explicables y trazables, posibilidad de ignorar o escalar y ninguna ejecución o decisión vinculante. Una ampliación futura requiere sus gates de seguridad y jurídico.

## Paquete de validación comercial
Preparar para el primer inversor o entidad colaboradora: problema, flujo demostrable, reducción esperada de fricción, trazabilidad y evidencias, conciliación, seguridad, límites actuales, métricas a observar y roadmap.

Hipótesis a medir durante el piloto:
- reducción de coordinación manual y duplicación;
- centralización de evidencias y estados;
- detección temprana de inconsistencias;
- mejor preparación y seguimiento de incidencias;
- valor percibido de las recomendaciones Premium.

No presentar ahorro, reducción de disputas o rendimiento como garantizados antes de disponer de resultados medidos.

La prueba real se coordinará separadamente con la parte colaboradora correspondiente; este bloque solo prepara material y criterios.
