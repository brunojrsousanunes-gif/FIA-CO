# FIA&CO — Data Room Index v1

> Índice interno. No compartir externamente sin revisión previa de confidencialidad, PII, secretos y exactitud.

## 01 — Corporate
- estructura societaria cuando exista;
- cap table;
- acuerdos de socios;
- propiedad intelectual y cesiones;
- marcas/dominios.

## 02 — Producto
- arquitectura funcional;
- roadmap;
- demo y flujo de operaciones;
- pricing Base/Plus;
- backoffice/funnel;
- documentación de producto.

## 03 — Tecnología
- arquitectura técnica;
- CI/tests;
- política de seguridad;
- gestión de secretos;
- dependencias;
- plan de producción;
- resultados de pentest/auditorías cuando existan.

Nunca incluir secretos, tokens, claves o credenciales en el data room.

## 04 — Legal / Compliance
- términos y condiciones validados;
- privacidad/RGPD;
- contratos de proveedores;
- evaluación del modelo de pagos/custodia/intermediación;
- KYC/AML cuando aplique;
- procedimiento de reclamaciones;
- memorandos/validaciones externas.

## 05 — Mercado
- definición de segmentos;
- entrevistas B2B anonimizadas/agregadas;
- objeciones;
- evidencia de interés en pilotos;
- análisis competitivo con fecha y fuentes.

## 06 — Finanzas
- modelo financiero 36 meses;
- unit economics;
- presupuestos reales;
- cash plan/runway;
- escenarios y sensibilidades;
- uso de fondos.

Separar siempre proyecciones de resultados históricos/reales.

## 07 — Tracción
- pilotos;
- operaciones reales agregadas;
- GMV;
- ingresos;
- conversión;
- CAC;
- retención/repetición;
- pipeline B2B.

Hasta disponer de datos reales, esta carpeta debe indicarse claramente como `NO REAL TRACTION DATA YET`.

## 08 — Equipo
- fundador;
- advisors cuando existan;
- plan de contratación;
- funciones clave pendientes.

## 09 — Riesgos
- risk register;
- incidentes;
- mitigaciones;
- dependencias críticas;
- seguros cuando existan.

## Reglas de acceso
- mínimo privilegio;
- acceso por necesidad;
- versiones finales separadas de borradores;
- retirada de PII innecesaria;
- registrar qué se comparte y con quién cuando se active la fase externa.
