# ANIMAL-PROFILES-PREP

Estado: **PREPARED_NOT_VALIDATED**. Esta capa prepara perfiles por especie y tipo de viaje; no habilita transporte real ni sustituye revisión veterinaria o jurídica.

Cada perfil deberá contener especie/grupo, tipo de viaje, aptitud para transporte, requisitos de transportista y vehículo, personal competente, documentación, controles de bienestar, contingencia, versión de fuentes y estado de validación profesional.

No se codifican límites universales de duración, descanso, agua, alimentación, densidad, temperatura, separación u otros parámetros sensibles mientras no exista un perfil concreto validado para el escenario aplicable. El comportamiento por defecto es `REVIEW_REQUIRED`.

Antes de pasar un perfil a uso real deben cerrarse conjuntamente: jurisdicción y normativa aplicables, validación veterinaria/jurídica del perfil, autorizaciones del operador y medio cuando procedan, formación del personal, documentación acompañante, contingencia y gate de seguridad/productivo correspondiente.
