# FIA&CO — Acciones reservadas al Founder en V1

Este documento separa el trabajo que puede avanzar técnicamente del que requiere decisión, contacto o autorización humana del Founder.

## Ahora — no bloquea desarrollo

No necesitas hacer nada para que continúe el desarrollo técnico de V1. FIA&CO permanece `DEMO_ONLY` y los proveedores siguen sin puntuación final.

## Cuando preparemos shortlist de proveedores

Acciones `FOUNDER_ACTION_REQUIRED`:

1. **Pagos / banca**
   - Solicitar o compartir información comercial de Cecabank y Sipay/Uinku.
   - Confirmar si se desea explorar el modelo de acceso de Bizum.
   - Elegir qué bancos españoles merece la pena contactar primero.

2. **Identidad / KYB / KYC**
   - Elegir si se prioriza coste, experiencia de usuario, cobertura europea o profundidad KYB.
   - Autorizar contactos comerciales cuando exista una shortlist técnica.

3. **Ciberseguridad**
   - Decidir presupuesto aproximado para revisión externa/pentest cuando corresponda.
   - Aprobar la empresa auditora antes de contratar.

4. **Cloud / infraestructura**
   - Elegir presupuesto y preferencia de residencia/región cuando el Production Gate permita avanzar.
   - Autorizar cualquier alta con coste o credencial productiva.

## Información que debes traer de una conversación comercial

No hace falta negociar técnicamente. Basta con guardar/compartir:
- precio y mínimos mensuales;
- coste de alta o integración;
- disponibilidad de sandbox;
- SLA/soporte ofrecido;
- duración y salida del contrato;
- tratamiento y residencia de datos;
- requisitos de volumen o exclusividad;
- persona/contacto comercial y documentación recibida.

## Decisiones que nunca se automatizan

- firma de contratos;
- aceptación de deuda, inversión o dilución;
- aprobación de presupuesto real;
- introducción de secretos productivos;
- activación de dinero real o PII real;
- selección final de proveedor;
- autorización de enforcement de riesgo.

## Regla

El sistema puede ordenar evidencia y generar una recomendación comparativa, pero la decisión final permanece en `FOUNDER`.
