# FIA&CO — Investor Ready Gate

Objetivo: determinar cuándo FIA&CO está suficientemente consolidado para iniciar financiación formal sin esperar al lanzamiento comercial completo.

## Gate mínimo

### Producto
- [x] Demo funcional y estable con datos ficticios.
- [x] Motor de operaciones y controles de estado.
- [x] Pricing Base/Plus ejecutable y probado.
- [x] Backoffice/funnel demo y métricas económicas.
- [ ] Demo narrativa específica para inversores validada de extremo a extremo.

### Economía
- [x] Separación entre GMV, ingresos, gasto externo y coste sombra del fundador.
- [x] Guardrail NO_SCALE para margen negativo.
- [ ] Modelo financiero 36 meses: conservador/base/agresivo.
- [ ] Necesidad de capital y runway objetivo cuantificados.
- [ ] Sensibilidad CAC, conversión, ticket, mix Plus y ciberseguridad.

### Mercado
- [x] Verticales iniciales: transporte, maquinaria industrial/agrícola y construcción.
- [ ] 5–10 conversaciones B2B cualificadas documentadas.
- [ ] Señales de interés en piloto / disposición a pagar.
- [ ] Objeciones y requisitos repetidos incorporados al roadmap.

### Riesgo
- [x] Baseline de seguridad y gates de producción definidos.
- [x] Custodia/movimiento de fondos y PII real excluidos antes de gates.
- [ ] Ruta jurídica/regulatoria revisada externamente.
- [ ] Estimaciones/alcance de pentest, SOC/MDR y proveedores críticos.

### Material de financiación
- [ ] Pitch deck 10–12 diapositivas.
- [ ] One-pager ejecutivo.
- [ ] Data room indexado.
- [ ] Roadmap 12–18 meses y uso de fondos.
- [ ] Estrategia de financiación: equity/deuda/ayudas/socio industrial.

## Semáforo
- ROJO: falta producto/economía básica o existen riesgos no delimitados.
- ÁMBAR: documentación interna lista pero falta evidencia B2B o validación externa.
- VERDE / INVESTOR READY: demo + modelo financiero + materiales + evidencia comercial suficiente + riesgos delimitados.

## Principio de dilución
No fijar porcentaje a ceder antes de cuantificar capital necesario, runway e hitos comprados por ese capital. Priorizar la combinación que alcance el siguiente hito con dilución y riesgo financiero razonables.

## Aviso
Cuando todos los elementos críticos estén en verde, marcar explícitamente el repositorio como `INVESTOR READY` y preparar la salida formal a financiación. Hasta entonces se permiten conversaciones exploratorias, pero no presentar proyecciones internas como resultados reales.
