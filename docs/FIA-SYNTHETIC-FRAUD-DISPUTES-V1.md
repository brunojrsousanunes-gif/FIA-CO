# FIA&CO — Fraude y disputas sintéticas v1

Estado: `SYNTHETIC_ONLY / ZERO_COST / NO_FINANCIAL_ACTIONS`.

Se ensayan doce conflictos ficticios: entrega falsa, negación de entrega, evidencias contradictorias, producto dañado o incompleto, cancelación tardía, devolución duplicada, cambio de condiciones, señales de colaboración fraudulenta, suplantación, presión para liberar, reclamación fuera de plazo y falta de respuesta.

FIA&CO únicamente puede continuar, pedir evidencia, bloquear, abrir disputa, solicitar revisión humana o preparar una instrucción ficticia para un PSP. En esta campaña no se genera ninguna instrucción financiera.

Reglas permanentes:

- no decidir automáticamente quién tiene razón;
- no producir conclusiones legales;
- no verificar identidades reales;
- no mover, liberar ni devolver dinero;
- mantener congelada la operación cuando exista riesgo;
- exigir referencias de evidencia minimizadas;
- reservar el fondo de la disputa a una persona autorizada.

Un resultado positivo permite continuar las simulaciones, pero no demuestra capacidad real para resolver fraudes o controversias.
