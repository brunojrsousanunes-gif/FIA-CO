# Security Policy

FIA&CO está en fase de desarrollo y precomercialización. No deben introducirse datos personales, credenciales, secretos ni información financiera real en demos, issues o pull requests públicos.

## Reporte responsable
Si detectas una vulnerabilidad, evita publicar detalles explotables en un issue público. Contacta al responsable del repositorio por un canal privado disponible en GitHub y facilita: componente afectado, impacto, pasos mínimos para reproducir y cualquier mitigación temporal conocida.

## Alcance actual
La demo no está autorizada para custodiar o mover fondos ni para procesar documentación real. Antes de producción se requiere revisión de arquitectura, threat model, controles de acceso, gestión de secretos, logging, backups, respuesta a incidentes y pentest/revisión externa equivalente.

## Severidad
Hallazgos críticos o de alta severidad bloquean lanzamiento y activación de clientes reales hasta su resolución o aceptación formal del riesgo por el responsable del proyecto.
